About

I'm a software developer who cares about building applications that stay reliable as they grow, and about finding practical, honest uses for artificial intelligence.

With a background in mathematics and computer science, my work and interests span full-stack web development, REST API design and integration, and database modelling. On the AI side, I focus on LLM-powered applications: retrieval-augmented generation, AI API integration, and automating repetitive workflows so people can spend time on work that needs judgment.

I value maintainable code over clever code, interfaces that feel effortless on any screen, and architecture that makes the next feature easier rather than harder. I'm based in Dar es Salaam and enjoy working with teams anywhere.
